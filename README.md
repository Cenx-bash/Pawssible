# 🐾 Pawssible – Pet Care Management System

A web-based pet care management platform designed to help pet owners organize their pets' information, maintain medical records, access pet care services, and schedule appointments in one centralized system.

---

## 📌 Overview

**Pawssible** aims to make pet care management more accessible and organized through a centralized web application. It provides different functionalities for pet owners, veterinarians, service providers, and administrators through role-based access.

## ✨ Features

- **User Authentication** – User registration, login, and account management.
- **Pet Management** – Create, view, and manage pet profiles.
- **Medical Records** – Maintain pet health histories and medical information.
- **Pet Care Services** – Browse available pet-related services.
- **Appointment Scheduling** – Schedule and manage appointments.
- **Reviews & Ratings** – Share feedback about pet care services.
- **Role-Based Access Control** – Manage system permissions based on user roles.

## ⚙️ Installation and Setup

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- [MySQL](https://www.mysql.com/)
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project Directory

```bash
cd Pawssible
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure the Database

- Create a MySQL database named `pawssible`.
- Import the provided database file, if available.
- Configure your database credentials in the backend configuration.

### 5. Run the Application

```bash
npm start
```

*Refer to the project's package.json for the correct startup command.*
